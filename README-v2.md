# Text Swap 2.0

Новая версия утилиты для [исходного репозитория](https://github.com/Log0user/Text---Swap_en-ru-reg).
Самостоятельный вариант исходников, который можно перенести в отдельную ветку репозитория. **Существующий проект не перезаписан.**

- C# / WinForms / .NET 10, Windows 10/11 x64;
- преобразование RU ↔ EN по соответствию клавиш (`ghbdtn` → `привет`, `.uf` → `юга`, `ghbdtn/` → `привет.`);
- четыре режима: авто по преобладающему алфавиту, по фрагментам (экспериментально), принудительно EN → RU и RU → EN;
- исправная обработка регистра и сохранение символов, которых нет в выбранной исходной раскладке, включая переносы строк;
- преобразование текста в окне, верхний/нижний регистр, обмен с буфером;
- **F9**: открыть окно и преобразовать текст из буфера, результат вернуть в буфер;
- **Ctrl+F9**: попытаться скопировать выделенный текст в активном приложении, преобразовать и вставить на место;
- сворачивание/закрытие в трей; меню трея; защита от запуска второго экземпляра;
- настройки направления и поведения сохраняются сразу и загружаются при следующем запуске;
- «О программе» с версией, ссылкой на GitHub и кнопками проверки/установки обновления;
- автоматических фоновых запросов нет. Интернет нужен **только по нажатию «Проверить обновление» или «Обновить»**.

## Сборка на Windows

Установи **.NET SDK 10**, открой PowerShell в корневой папке проекта:

```powershell
dotnet run --project Tests/Tests.csproj -c Release
dotnet run --project TextSwap/TextSwap.csproj -c Release
```

Для одного автономного EXE, не требующего установки .NET на компьютере пользователя:

```powershell
dotnet publish TextSwap/TextSwap.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false -o publish
```

Готовый файл: `publish\TextSwap.exe`. Отдельных NuGet-пакетов проект не использует.

## Настройки

Сохраняются в `%LOCALAPPDATA%\TextSwap\settings.json` через временный файл. Удаление/замена EXE не удаляет этот файл. Программа не пишет настройки в реестр. EXE переносимый, но настройки привязаны к профилю пользователя Windows.

## Как работают режимы

- **Авто:** сравнивает количество английских и русских букв во всём тексте. Переводит символы определённой раскладки, буквы другого алфавита оставляет. Когда букв обоих алфавитов поровну, ничего не меняет.
- **По фрагментам:** для каждого набора букв и прилегающих клавиатурных знаков выбирает собственное направление. **Не является интеллектуальным словарём** и может преобразовать правильно написанное слово `Python` в неправильное.
- **EN → RU / RU → EN:** строгая раскладка, без анализа содержимого. Знаки меняются по клавишам: `.` может означать `ю`, а `/` — точку. Настоящую пунктуацию от ошибочно набранных букв без контекста гарантированно не отличить.
- При отсутствии букв автодетектор оставляет исходный текст, поскольку направление неизвестно.

## Особенности Ctrl+F9

Для замены выделения используется обычная последовательность `Ctrl+C`, буфер обмена, `Ctrl+V`, отправляемая в активное приложение через Windows `SendInput`. Это универсальный, но **не абсолютно надёжный** метод:

- приложение должно поддерживать Ctrl+C/V; некоторые терминалы, игры, окна с правами администратора и защищённые поля могут игнорировать команду;
- после операции **буфер обмена содержит преобразованный текст** — прежнее содержимое не восстанавливается;
- вставка производится **как обычный текст**, поэтому форматирование выделения может измениться;
- преобразование не отправляет текст в интернет; при неудачном копировании текст не заменяется;
- в очень медленных приложениях ожидание выделения (около 200 мс) может оказаться недостаточным. Перед массовым использованием стоит проверить на привычных редакторах.

Глобальные горячие клавиши можно полностью отключить в окне настроек.

## Обновления (важно)

В окне «О программе» программа вручную обращается к **публичному GitHub API** данного репозитория, получает последний стабильный Release, сравнивает с версией приложения и ищет **ровно** два файла:

- `TextSwap-win-x64.exe`
- `TextSwap-win-x64.exe.sha256`

Затем EXE скачивается с `github.com/Log0user/Text---Swap_en-ru-reg/releases/download/`, сравнивается с опубликованной SHA-256, запускается как временный обновлятор, ожидает завершения старого процесса, заменяет исходный EXE и запускает приложение заново. В установочной папке останется `TextSwap.exe.previous` для отката. Если не хватает прав записи (например, `Program Files`), обновление не сработает без ручного переноса EXE в доступную пользователю папку. Настройки в `%LOCALAPPDATA%` при этом не затрагиваются.

**SHA-256 проверяет соответствие скачанного файла релизу, но не защищает от взлома самого репозитория или подмены учётной записи владельца.** Не является криптографической подписью разработчика.

Сейчас в старом репозитории нет готового релиза с такими файлами. Обновление заработает **только после публикации новой версии в этом же репозитории**. Включённый workflow `.github/workflows/build.yml` выполняет тесты, собирает EXE на Windows и по Git-тегу `v2.0.0` выпускает GitHub Release с контрольной суммой. Для последующих обновлений увеличивай `<Version>` в `TextSwap/TextSwap.csproj`, затем создавай соответствующий тег (`v2.0.1` и т. д.). Если релиз опубликован вручную, имена файлов должны совпадать.

## Проверка, публикация, лицензия

GitHub Actions выполняет тесты на Windows при отправке изменений в ветку и при публикации тегов. Исходники автоматически НЕ загружаются в репозиторий из этого архива: сначала смотри diff и проверь локальную сборку.

Проект продолжает исходную лицензию **AGPL-3.0**. При переносе файлов обязательно сохрани оригинальный `LICENSE.txt` из репозитория. Лицензия доступна по адресу: https://github.com/Log0user/Text---Swap_en-ru-reg/blob/master/LICENSE.txt .

Архив подготовлен как исходный проект для тестирования: **собрать/испытать Windows EXE в текущем окружении не удалось** (нет .NET SDK и Windows). Реализация требует проверки на настоящей Windows, особенно глобальных хоткеев и механизма обновления.
