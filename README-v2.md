# Text Swap 2.0.1

Современная версия Windows-приложения для перевода текста, набранного в неправильной раскладке. Старые исходники остались в `Swap_en-ru/`.

## Возможности

- Перевод символов по клавишам Windows RU ↔ US, включая пунктуацию: `ghbdtn` → `привет`, `gjqltn rjirf vbvj .uf` → `пойдет кошка мимо юга`, `ghbdtn/` → `привет.`.
- Режимы: авто по большинству букв, экспериментальный по фрагментам, EN → RU, RU → EN. Неизвестные символы, переносы строк и табуляция сохраняются.
- **Новые темы 2.0.1:** «Как в Windows» (по умолчанию), «Светлая» и «Тёмная». Выбор применяется сразу и сохраняется. В системном режиме учитывается цветовая схема Windows.
- Ввод/результат, буфер обмена, изменение регистра.
- F9: перевести текст из буфера, показать результат и поместить его обратно в буфер.
- Ctrl+F9: попытаться копировать выделение из другой программы, конвертировать и вставить его обратно (экспериментальная функция).
- Трей, горячие клавиши и сохранение параметров.
- «О программе»: версия, GitHub, ручное скачивание и установка обновления.
- **Новая кнопка 2.0.1 «Откатить версию»**: появляется при наличии `TextSwap.exe.previous`. Восстанавливает предыдущий EXE, а вытесненный новый сохраняет в `.previous`.

## Сборка (Windows 10/11 x64)

Понадобится .NET **SDK** 10. В корне проекта запусти `build.cmd` или:

```powershell
dotnet run --project Tests/Tests.csproj --configuration Release
dotnet publish TextSwap/TextSwap.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false -o publish
```

Итоговый автономный файл: `publish\TextSwap.exe`. Отдельных NuGet-пакетов не требуется.

## Обновление и откат

1. Выпущенный EXE проверяет **по нажатию** актуальную стабильную версию из GitHub Releases этого репозитория. Фоновых запросов нет.
2. Если есть новая версия, скачивает `TextSwap-win-x64.exe` и соответствующий `.sha256`, сверяет контрольную сумму, затем запускает временную копию обновлятора.
3. Обновлятор ждёт завершения приложения, заменяет EXE и оставляет ровно один бэкап `TextSwap.exe.previous` рядом с исполняемым файлом.
4. В версии 2.0.1 кнопка отката использует временную копию текущего EXE для восстановления предыдущего. Она доступна только при существующем бэкапе и требует подтверждения. Права записи в папку приложения обязательны.
5. **Важно:** если выполнить откат на 2.0.0, кнопки отката больше не будет, так как её ещё нет в старой программе. Вернуться на 2.0.1 можно через стандартное обновление.

Для проверки обновления с 2.0.0 до 2.0.1 опубликуй на `master` тег `v2.0.1` **после** завершения тестирования PR. Workflow `.github/workflows/build.yml` создаст релиз и оба файла. Изменения текущей ветки без релиза не будут находиться механизмом обновления.

**Перед первым испытанием обновления/отката вручную скопируй существующий `TextSwap.exe` в отдельную папку.** Алгоритм проверки файлов протестирован на фиктивных файлах CI, но поведение с настоящим запущенным приложением и ограничения антивируса необходимо проверить на Windows. Подлинность источника обновления зависит от безопасности GitHub-репозитория; SHA-256 сама по себе не является подписью автора.

## Настройки

Путь: `%LOCALAPPDATA%\TextSwap\settings.json`. Сохраняются выбор темы, направление преобразования, работа горячих клавиш и поведение трея. Обновление и откат не меняют настройки и не затрагивают реестр; portable-EXE хранит настройки в профиле Windows.

## Ограничения

- Две раскладки — стандартные US/Windows RU, не полноценный переводчик.
- «По фрагментам» — простой эвристический алгоритм, не словарь. Может портить настоящие английские слова.
- Ctrl+F9 меняет содержимое буфера и зависит от `Ctrl+C` / `Ctrl+V`; в играх, терминалах, запущенных с повышенными правами программах и специальных полях может не работать.
- Загрузка обновления и откат требуют права записи в папку EXE.
